# M8 — Main UI
Model: Sonnet. Goal: simple, clean app: upload audio, download prompts, upload images, Submit, preview, download.
Work in `frontend/`. Use `frontend-design` skill guidance if available for a polished look. Keep it light.

## Screens (single flow, stepper at top)
| # | Screen | Content |
|---|--------|---------|
| 1 | Project | new project, name, audio upload (drag and drop), project list |
| 2 | Transcript | progress bar while Whisper runs; transcript text view for spelling fixes |
| 3 | Plan | shows "waiting for plan" with the command to run in Claude Code; then scene list |
| 4 | Prompts | scene summary + big "Download prompts.txt" button + copy-per-prompt buttons |
| 5 | Images | one Upload button (files or folder) + drop zone; thumbnails; Submit button |
| 6 | Match check | only if needed: image vs prompt text, pick correct match, one-click fix |
| 7 | Preview/Render | Remotion Player preview (540p), Render button, progress, video player, Download |

## Tasks
1. Vite + React + TS + Tailwind setup (already installed); routes with react-router.
2. API client with TanStack Query; polling for status every 2s only while a job runs.
3. zustand store: current project id, step, UI state.
4. Upload component: `react-dropzone`, folder support (`webkitdirectory`), file count + size, progress.
5. Image grid: thumbnails (object URLs), counts "42 uploaded / 45 prompts", missing prompts checklist.
6. Match check screen: shows each `review` item with top-3 suggested prompts; Confirm / Mark unused.
7. Preview using `@remotion/player` with the filled composition.json at low resolution.
8. Render: button for preview render and final render; ETA from status; download link.
9. Subtitles toggle (Telugu captions on/off) saved in composition meta.
10. Error toasts with the hint from the API; retry buttons.
11. Framer Motion only for UI transitions (step changes, cards), never inside video.

## UX rules
- One primary button per screen. Large, clear labels in English (optionally Telugu hints).
- The user never types file names or picks folders on disk: upload only.
- Disable Submit until at least all required prompts have an image or the user ticks "skip missing".
- Show what is happening: step name, percent, estimated time.
- Responsive for laptop widths; dark theme; no heavy shadows or animations.

## Done when
- A full run from the UI produces out.mp4 with only these user actions: upload audio, run /plan once,
  download prompts, upload images, Submit, press Render.
- Refreshing the page restores the current step from the backend state.
- `tsc --noEmit` and `npm run build` pass.
