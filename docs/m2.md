# M2 — Component Library, Transitions, Effects
Model: Opus. Goal: every layer type in `schemas.md` works; the "documentary + motion graphics" look.
Work in `remotion/` only. Build in the order below and render a test clip after each group.

## Group A — Core layers
1. `IconPop` (Lucide, spring pop, stroke draw option).
2. `Callout` (arrow, circle, underline, box) using `@remotion/paths` for draw-on.
3. `ShapeAnim` (line/rect/circle draw, mask reveal via clip-path).
4. `Caption` / lower-third and `HighlightText` word highlight (colored marker sweep).
5. `Counter` (count-up with easing, unit, thousands separators).

## Group B — Data and map
6. `Chart`: bar, line, pie animated with d3-scale/d3-shape; labels in English.
7. `MapLayer`: d3-geo + topojson; regions highlight, route draw, animated pins. Include India + world base data in `VIDEO_ENGINE/remotion/public/geo/` (ask user if download is needed).

## Group C — Depth and polish
8. `ImageLayer` parallax: z-based speed, soft drop shadow, optional mask reveal.
9. `Effect`: sparkle, burst, glow, checkmark, particles (SVG, seeded random, `@remotion/noise`).
10. `StockVideo` with `<OffthreadVideo>` loop and opacity.
11. `Subtitles`: Telugu word-highlight captions from transcript words, toggled by `meta.subtitles`.
12. `FilmLook`: add light-leak overlay (CSS gradients, no external video).

## Group D — Transitions
13. Wire `@remotion/transitions`: fade, slide, wipe, flip, clock-wipe.
14. Custom: `zoom-through`, `light-leak`, `blur`, `mask-shape`, `match-move`, `particle`.
15. Transition picker util `pickTransition(prev, mood)` that never returns the previous type.

## Group E — Patterns
16. Implement all 16 patterns from `components.md` in `src/patterns/`, each returning a layers array
    from `(scene, params)`.
17. Pattern gallery composition: one scene per pattern with sample images, for visual review.

## Acceptance
- `tests/fixtures/gallery.json` renders all patterns at 540p without errors.
- Each transition type appears at least once; no two adjacent transitions are equal.
- Render time check: report seconds per scene on this CPU; flag any scene above 3x its duration.
- Remotion Studio loads without console errors; `tsc --noEmit` passes.

## Performance guards
- Avoid CSS `filter: blur` on large layers every frame; use prerendered blurred copy when possible.
- Cap particles at 60 per effect. Limit simultaneous image layers to 5.
- Memoize heavy d3 computations with `useMemo`.

## Review with user
After Group C and after Group E render a short clip and ask: "Which looks weakest?" Fix that first.
Tune style tokens (easing, timing) before adding more features.

## After
Tick tasks, commit `M2: components`, `/clear`, M3 with Haiku/Sonnet.
