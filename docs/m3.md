# M3 — Whisper: audio -> transcript.json
Model: Haiku or Sonnet. Goal: Telugu audio to word-level transcript, CPU only, saved and cached.

## Inputs
`projects/{id}/audio.mp3` (any format ffmpeg reads).

## Tasks
1. `backend/config.py`: PROJECT_ROOT, model cache env vars (HF_HOME, TORCH_HOME, U2NET_HOME) set before imports.
2. `backend/audio_utils.py`: convert to 16 kHz mono wav with ffmpeg; get duration; silence detection (pydub or ffmpeg silencedetect).
3. `backend/transcribe.py`: faster-whisper `medium`, `device=cpu`, `compute_type=int8`,
   `language="te"`, `word_timestamps=True`, `vad_filter=True`.
4. Write `transcript.json` in the schema from `schemas.md`; validate with pydantic.
5. Progress: update `job.json` with percent from segment end / duration.
6. Cache: if transcript.json exists and audio hash unchanged, skip.
7. CLI: `python -m backend.transcribe projects/demo` prints segment count and duration only.
8. `backend/cuts.py`: sentence boundaries (pysbd on Telugu text, fall back to Whisper segment ends)
   plus silences > 0.35s; snap each cut to the nearest word end; write `cuts.json`.
9. Tiny review helper: `python -m backend.show_transcript projects/demo` prints a numbered transcript
   (time + text) so the user can correct it in `transcript.json` or `transcript_fixed.json`.

## Transcript correction
Whisper Telugu can have errors. If `transcript_fixed.json` exists, all later steps use it.
Keep word timestamps when the user edits text: map edited segment text onto existing word times
proportionally, or ask the user to edit only spelling, not timing.

## Done when
- A 1-2 minute test audio gives a transcript with word timestamps and a cuts.json with plausible cuts.
- Running twice does not recompute (cache hit message).
- Memory stays under ~6 GB (check Task Manager once, report peak).
- Report real time taken (expected roughly 2-4x audio length on this CPU for `medium`).

## Fallbacks
- Out of memory or too slow -> switch to `small` via `WHISPER_MODEL` in config; tell the user.
- pysbd has no Telugu rules -> split on `.`, `?`, `!`, `।` and long pauses.

## Do not
- Do not call any external API. Do not download other models without asking.
- Do not print the whole transcript into the chat (token cost); show counts and 3 sample lines.

## After
Tick tasks, commit `M3: whisper`, `/clear`, M4 with Opus (planning quality matters).
