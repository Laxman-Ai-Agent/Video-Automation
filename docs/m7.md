# M7 — FastAPI Backend
Model: Sonnet. Goal: the same pipeline exposed as an API for the UI. No new business logic here:
endpoints call `pipeline.py` functions from M6.

## Tasks
1. `backend/main.py`: FastAPI app, CORS for the Vite dev origin, `uvicorn backend.main:app --reload`.
2. Project store: `projects/{id}/` created with a short slug id; `project.json` keeps name, created time, state.
3. Endpoints from `architecture.md`: create, transcribe, status, prompts download, assets upload,
   submit, match, match/fix, result, plus `GET /projects` (list) and `DELETE /projects/{id}` (ask first).
4. Uploads: `python-multipart`; accept many files and folders (relative paths flattened, name collisions
   get suffixes); size limits (50 MB per image, 500 MB audio); reject non-media types.
5. Background jobs: run long steps in a thread pool; one active job per project; cancel flag.
6. Progress: `GET /status` returns `{step, percent, message, error, waiting_for}`;
   `waiting_for` is one of `plan`, `images`, `review`, or null.
7. Plan waiting: when transcript and cuts exist but scene_plan.json does not, report `waiting_for: "plan"`
   and include the exact command text for the user to run in Claude Code.
8. Static serving: serve `out.mp4` and preview clips with range requests (video seeking works).
9. Error format: `{error:{code,message,hint}}` with HTTP codes; never leak file paths of other projects.
10. Tests with `pytest` + `httpx` TestClient for the happy path using fixtures.

## API behaviour details
- Upload is idempotent: re-uploading the same file name replaces it and marks matching stale.
- `submit` is rejected while required prompts are missing unless `force=true`.
- `match/fix` body: `{"file":"IMG_01.png","n":7}` or `{"file":"x.png","unused":true}`.
- Prompt download returns `text/plain` with filename `prompts_{project}.txt`.
- All JSON responses validated with pydantic response models.

## Security basics (local app)
- Bind to 127.0.0.1 only. No auth needed, but do not expose to the network.
- Sanitize file names; never write outside the project folder.
- Do not return or log environment variables or keys.

## Done when
- Using `curl`/Swagger (`/docs`) the full flow works: create -> transcribe -> (plan) -> prompts -> upload -> submit -> result.
- Status endpoint reflects each step within 1s of change.
- `pytest -q` passes; `/docs` lists all endpoints with schemas.
