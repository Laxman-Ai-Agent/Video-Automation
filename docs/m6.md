# M6 — End-to-End CLI
Model: Sonnet. Goal: one command chain runs the whole pipeline without the UI.
Phase 1 still needs `/plan` in Claude Code; everything else is code.

## Commands (target)
```
python -m backend.cli new demo --audio path\to\audio.mp3     # create project folder
python -m backend.cli transcribe demo                          # M3 steps
python -m backend.cli plan-input demo                          # builds plan_input.txt
#   -> user runs /plan demo in Claude Code
python -m backend.cli prompts demo                             # shows path of prompts.txt
#   -> user generates images, copies them into projects/demo/assets/inbox/
python -m backend.cli build demo                               # match, checks, cutouts, fill, render
python -m backend.cli status demo                              # step + warnings
```

## Tasks
1. `backend/cli.py` with the subcommands above (argparse, no heavy deps).
2. `backend/pipeline.py`: step functions with a registry; each step reads inputs, writes outputs,
   updates `job.json` (`step`, `percent`, `error`), and is skippable when outputs are fresh.
3. Dependency check per step (missing input -> clear message, e.g. "run /plan first").
4. `backend/render.py`: call `npx remotion render` with composition path, `--concurrency`,
   preview flag (540p/15fps) and final flag (1080p/30fps); stream progress into job.json.
5. Review gate: if match_report has `review` or required `missing`, stop and print the list;
   `--force` fills fallbacks and continues.
6. `credits.json` creation if Pexels clips are used (M9 may add stock; keep the hook).
7. Logging to `projects/{id}/log.txt`; errors keep the traceback in the log, short message on screen.
8. End-to-end run on the 1-2 minute test project; record timings per step in `projects/{id}/timings.json`.

## Done when
- Starting from audio + `/plan` + images, `build` produces `out.mp4` with audio in sync.
- Re-running `build` after replacing one image only redoes matching for that image and the render.
- A failure in any step leaves earlier outputs intact and explains how to resume.
- Final video reviewed by the user with the checklist below.
