# M0 — STATUS.json + Dashboard
Model: Sonnet. Goal: live, simple progress page so the user sees done/pending tasks.

## Inputs
`STATUS.json` at project root (provided). Format in `schemas.md`.

## Tasks
1. Create `dashboard/` (Vite + React + TS + Tailwind + recharts + lucide-react).
2. Read STATUS.json: copy/serve it through Vite `public/` via a small dev proxy or a script
   `scripts/sync_status.py` that copies root STATUS.json to `dashboard/public/status.json`.
3. Poll `status.json` every 5s with `fetch` (no cache: add `?t=Date.now()`).
4. Overall progress bar: done tasks / total tasks, percent.
5. Milestone bar chart (recharts): % complete for M0-M9.
6. Current milestone checklist: done / doing / todo icons.
7. Counters: done, pending, total; "last updated" time.
8. Helper `scripts/update_status.py <task name> done` to tick tasks (used after each task).
9. README lines in `STATUS.md` explaining how to run: `cd dashboard && npm run dev`.

## UI rules
- One page, no router, no heavy animation. Dark theme, large readable numbers.
- Layout: top = overall bar; left = milestone chart; right = current checklist.
- Works with zero backend. Read only, never writes.

## Done when
- `npm run dev` shows correct percentages from STATUS.json.
- Running `python scripts/update_status.py "Camera.tsx" done` changes the page within 5s.
- `tsc --noEmit` passes.

## Do not
- Do not add a database, auth, or websockets.
- Do not use more than recharts + lucide for visuals.

## After
Tick M0 tasks, commit `M0: dashboard`, tell user to run `/clear`, start M1 with Opus (`/model`).

## Files to create
```
dashboard/src/App.tsx            layout + polling hook
dashboard/src/useStatus.ts       fetch status.json every 5s
dashboard/src/components/        ProgressBar.tsx, MilestoneChart.tsx, Checklist.tsx, Counters.tsx
scripts/sync_status.py           copy STATUS.json -> dashboard/public/status.json (loop every 2s with --watch)
scripts/update_status.py         tick a task, set milestone status, update "updated"
```

## STATUS.json behaviour
- A milestone is `done` when all its tasks are done, `doing` when some are, else `todo`.
- `update_status.py` recomputes milestone status and the `updated` timestamp.
- Task names are matched exactly (case-insensitive). Unknown name -> print the closest names, do not guess.
- Never rewrite the whole file by hand; always use the script.

## Chart details
- Bar chart: x = M0..M9, y = percent done, color by status (done green, doing amber, todo gray).
- Overall bar shows "12 / 58 tasks (21%)". Pending = total - done.
- Empty/missing file: show "waiting for status.json" instead of crashing.

## Acceptance test (run in order)
1. `python scripts/sync_status.py --watch` in terminal A; `npm run dev` in terminal B.
2. Open the printed localhost URL; confirm 0 done initially (or current state).
3. `python scripts/update_status.py "Create dashboard project" done`.
4. Page updates within 5 seconds; percentage and chart change.
5. Stop the watcher; page keeps showing last data without errors.
