# M5 — Upload Handling, Matching, Checks
Model: Sonnet. Goal: user's images (any names, any order) are saved, matched to prompts, checked,
cut out where needed, and placed into composition slots. Zero Claude tokens at runtime.

## Tasks
1. `backend/assets.py`: accept files or a folder; save to `projects/{id}/assets/raw/`;
   keep original names; ignore non-images; convert webp/jpg/png to RGB/RGBA PNG copies in `assets/work/`.
2. Filename matcher: `^\d{1,3}` (e.g. `07.png`, `7-river.jpg`) -> prompt number.
3. `backend/matcher.py`: CLIP `ViT-B-32` (open_clip, CPU, batch of 8). Text from prompts_map,
   image from remaining files. Cosine matrix -> `scipy.optimize.linear_sum_assignment`.
4. Status rules: `ok` (score >= 0.22 and margin >= 0.03), `review` (otherwise), `missing`, `unused`.
5. Role-aware hints: icons/objects prefer images with mostly-white background (OpenCV border check);
   if a candidate disagrees with role, lower the score a little, do not hard-reject.
6. `backend/checks.py`:
   - resolution: hero images need width >= 1920 (else `low_res`, cap zoom to 1.05)
   - ratio: compare with prompt ratio; tolerate 5% (else `bad_ratio`, plan center-crop)
   - blur: Laplacian variance threshold (`blurry`)
   - duplicates: imagehash distance <= 4
7. `backend/focus.py`: focus point from OpenCV saliency (spectral residual) or face detect; store [x,y].
8. `backend/bg_remove.py`: rembg `u2netp` for icon/object roles; output `assets/cutouts/NN.png`.
   Skip if the image already has alpha.
9. `backend/fill_slots.py`: write file paths and focus into composition.json; copy needed files into
   `VIDEO_ENGINE/remotion/public/projects/{id}/`; apply fallbacks from `architecture.md`.
10. Save `match_report.json` and print a short table (n, file, score, status).
11. Pytest with fixtures: 6 images renamed randomly -> all matched correctly; 2 swapped prompts detected as `review`.

## Done when
- With shuffled names, correct matches >= 90% on the fixture set; wrong/uncertain ones flagged `review`.
- Missing required prompts listed clearly; unused files listed.
- Run time for 50 images on CPU under ~2 minutes (report actual).
- Manual correction API: `apply_fix(project, {file: "x.png", n: 7})` updates report and composition.

## Notes
- Load CLIP once per process; free memory after matching (`del model; gc.collect()`).
- Pre-resize images to max 2560 px wide before embedding/checks to save RAM.
- All thresholds in `backend/config.py` so they can be tuned without code changes.
- Never send images to any LLM. Print only counts and a table.
