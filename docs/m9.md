# M9 — Polish
Model: Sonnet (visual tuning), Haiku (small fixes). Goal: raise quality from "works" to "beautiful".
Work from real renders. Ask the user which scenes look weakest; fix those first.

## Tasks
1. Transition variety audit: list transitions used per video; no adjacent repeats; mood match.
2. Camera polish: easing curves, subtle handheld drift option, focus-based zoom accuracy.
3. Typography: type scale, kerning, text shadows/scrims, safe margins, consistent highlight style.
4. Color: palette enforcement from `scene_plan.style`; optional LUT-like color grade overlay.
5. Parallax upgrade (optional): Depth Anything small (CPU) to generate depth maps; Remotion layers
   split by depth. Only if render time stays acceptable; otherwise keep 2.5D.
6. Particles and light effects tuning: density caps, only at emphasis moments.
7. Audio: optional background music track with auto-ducking under narration (librosa RMS envelope),
   volume curve in composition; music file provided by the user.
8. Beat-aware accents: small pulses on key words using word timestamps (not music beats).
9. Pexels stock-video support: `backend/stock.py` search/download clips by query, save to
   `VIDEO_ENGINE/remotion/public/stock/`, write `credits.json`; key read from env at runtime only.
10. Optional Lottie layer: only for user-provided files in `VIDEO_ENGINE/remotion/public/lottie/`.
11. Error handling pass: clear messages for missing fonts, corrupt images, ffmpeg failures, low disk.
12. Performance pass: measure render time per scene; cap heavy effects; add `--preview` quick mode.
13. Packaging: `README.md` (short), `requirements.txt`, `package.json` scripts, `start.bat` that launches
    backend, frontend, and dashboard.
14. Export extras: thumbnail frame picker, description text with credits, optional 9:16 variant (ask first).

## Quality loop
1. Render 540p preview, user reviews (yes/no checklist from M6).
2. Pick the 3 weakest scenes; adjust patterns/parameters.
3. Repeat until the user approves; then render final 1080p.

## Done when
- User approves a full-length video as "professional documentary + motion graphics".
- Fresh clone can run with `requirements.txt` + `npm install` + `start.bat` (documented steps).
- No unhandled exceptions in a run with 3 deliberately bad inputs (corrupt image, missing image, silent audio).

## Do not
- Do not add features the user did not ask for. Do not expand beyond 200 lines in any .md file.
- Do not raise render time above ~3x video length without telling the user.

## After
Tick tasks, commit `M9: polish`, update README, tell the user the project is complete.
