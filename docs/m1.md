# M1 — Remotion Base: JSON -> Video
Model: Opus. Goal: a hand-written `composition.json` + audio + 3 test images renders to mp4.
This milestone sets the visual quality bar; take time here. Work in `remotion/` only.

## Inputs
- `tests/fixtures/composition.sample.json` (create; 3 scenes, see `schemas.md`)
- `tests/fixtures/audio_test.mp3` (user provides 20-60s, any language)
- `tests/fixtures/img_01.png ... img_03.png` (user provides or use generated gradients)

## Tasks
1. Init Remotion (already created via create-video). Set 1920x1080, 30fps in `config.ts`.
2. Composition root: read `composition.json` (zod validate), compute total frames from `meta.duration`.
3. `<Audio>` master track from `meta.audio`.
4. `SceneRoot`: one `<Sequence>` per scene (from/duration from start/end).
5. Layer router (`registry.ts`): maps `layer.type` -> component. Unknown type -> skip + console warn.
6. `Camera`: push-in, pull-out, pan-left/right, static, zoom-to-focus using `interpolate` + transform.
7. `ImageLayer`: `<Img>` with Ken Burns, fade-in, position presets, `object-fit: cover`.
8. `HighlightText`: large headline with spring slide-up and fade; English font via google-fonts.
9. `Background`: gradient with slow drift.
10. `FilmLook`: vignette + subtle grain overlay (SVG noise, seeded).
11. Simple cut/fade between scenes (full transition set is M2).
12. Script `npm run render:test` -> `out/test.mp4` at 540p, 15fps for fast checks.
13. Script `npm run render:final` -> 1080p/30fps.
14. Telugu font check: render one text with Noto Sans Telugu; confirm no boxes.

## Quality bar (must see in the test video)
- Smooth slow camera push-in on hero image, no jitter.
- Text appears with easing, aligned to the audio timestamp in the JSON.
- Gradient + vignette + grain give a cinematic look, not flat.
- Audio length equals video length; first/last frames not cut.

## Done when
- `npx remotion render` of the sample produces mp4 that plays with audio.
- Changing a layer's `enter.at` in JSON visibly changes timing.
- `tsc --noEmit` passes; sample JSON validated by zod; invalid JSON gives a readable error.

## Notes
- Use `staticFile()` with files copied to `VIDEO_ENGINE/remotion/public/` by a helper script.
- Keep each component under ~120 lines. Prefer composition over config options.
- CPU render: use `--concurrency=3`; test at 540p first.
- Do not build Chart/Map/Counter yet (M2). Do not call backend.

## After
Tick tasks, `git commit -m "M1: remotion base"`, `/clear`, continue with M2 (Opus).

Create scenes 2 and 3 with different cameras (pan-left, pull-out) and one scene with no text.
